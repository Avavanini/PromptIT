# PromptIT 

PromptIT is an AI-powered web development platform that allows you to generate, visualize, and edit complete web projects simply by providing text prompts. 

By combining the power of Large Language Models with a seamless live-preview environment powered by Sandpack, PromptIT bridges the gap between idea and implementation, letting you build functional React applications in seconds.

## ✨ Features

- **AI-Powered Generation**: Describe what you want to build in the prompt input, and watch the AI architect a full React project structure along with the code.
- **Interactive Builder Workspace**: A fully-fledged web IDE featuring:
  - **File Explorer**: Browse the files and directories generated by the AI.
  - **Chat Panel**: Converse with the AI agent to iteratively refine your code, add features, or fix bugs.
  - **Live Progress Dashboard**: Track the agent's progress as it architects and writes your app.
- **Live Preview & Sandpack Integration**: Real-time rendering of your generated project directly in the browser.
- **AI Auto-Debugging**: An integrated Error Monitor captures runtime errors from the preview and automatically feeds them back to the AI for self-correction.
- **Project Management**: Save, view, and manage your projects across sessions.
- **Secure Authentication**: Built-in user registration and login system.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React.js powered by Vite
- **Routing**: React Router
- **Live Preview**: Sandpack (CodeSandbox's in-browser bundler)
- **Styling**: Modern CSS / UI Components

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (Mongoose)
- **Authentication**: JWT-based auth
- **AI Core**: Custom LLM integrations, content normalizers, diff patching, and code validation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- MongoDB instance (local or MongoDB Atlas)
- An AI API Key (e.g., OpenAI / Anthropic)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Avavanini/PromptIT.git
   cd builder-ai
   ```

2. **Setup the Backend:**
   ```bash
   cd server
   npm install
   ```
   Create a `.env` file in the `server` directory and add your environment variables:
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   AI_API_KEY=your_ai_api_key
   ```
   Start the backend server:
   ```bash
   npm start
   # or for development:
   npm run dev
   ```

3. **Setup the Frontend:**
   Open a new terminal window and navigate to the client folder:
   ```bash
   cd client
   npm install
   ```
   Create a `.env` file in the `client` directory (if required) and add:
   ```env
   VITE_API_BASE_URL=http://localhost:5000
   ```
   Start the frontend development server:
   ```bash
   npm run dev
   ```

## 📂 Project Structure

```text
builder-ai/
├── client/                 # React frontend application
│   ├── public/             # Static assets
│   └── src/
│       ├── api/            # Backend API communication
│       ├── components/     # Reusable UI components (ChatPanel, FileExplorer, etc.)
│       ├── context/        # Global React state (AppContext)
│       ├── pages/          # Full page views (BuilderPage, HomePage, AuthPage, etc.)
│       └── utils/          # Helpers (sandpackUtils, exportProject, etc.)
└── server/                 # Node.js backend application
    ├── config/             # Database & environment configurations
    ├── controllers/        # Request handlers (auth, project, chat)
    ├── middleware/         # Custom middleware (auth checks)
    ├── models/             # Mongoose schemas (User, Project)
    ├── routes/             # Express API routes
    └── services/           # Core AI logic (prompts, diffs, code validation)
```

## 📝 Usage
1. Register for an account or log in.
2. Enter your project idea in the prompt bar on the Home Page.
3. The AI will redirect you to the Builder Page, where it will begin scaffolding your project.
4. Preview the application in real-time in the preview panel.
5. Use the chat interface to instruct the AI to make modifications, style updates, or functional changes.
6. Once satisfied, export or publish your project!
